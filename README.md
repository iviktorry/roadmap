## 📌 Overview

This project serves as my personal learning tracker, organized into structured monthly modules and weekly milestones. It was built as a lightweight, single-page web application to provide a visual breakdown of concepts, progress bars, and completion statuses.

### Highlights:

- 📄 **Single-File Architecture:** Fully self-contained application (HTML, CSS, JS) generated seamlessly in one go.
- 🎯 **Structured Milestones:** Organizes learning goals into focused weekly checkpoints.
- 📊 **Progress Tracking:** Interactive interface to mark completed topics as my skills expand.

## 🧭 Learning Methodology & Progression

While I initially followed the roadmap sequentially step-by-step, my learning process has naturally evolved into an **adaptive, project-based approach**:

- ⚡ **Self-Paced & Flexible:** Topics are explored based on current project requirements rather than strictly following chronological order.
- 🛠️ **Pragmatic Learning:** I frequently build various side projects, marking off topics and technologies as I master them in real-world scenarios.
- 📈 **Continuous Progression:** The dashboard serves as a dynamic history of topics acquired along the way, reflecting real practical experience rather than just theoretical coverage.

## 🛠️ Local Usage

Since the application is contained within a single standalone file, no build step or package manager is required:

1. Clone the repository:
   ```bash
   git clone https://github.com/iviktorry/roadmap.git
   ```
2. Open index.html directly in any browser (or launch via VS Code's Live Server extension)
